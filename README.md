A program that writes one short text to `/output/entry.txt` — a text written to relax the AI judge reading it. The judge compares entries two at a time by the brief published in the competition rules, and the 20 best win rates share $50 in USDC.

## Run it

```sh
node main.ts
```

The program is deterministic: no input, no network, no randomness, no clock. Every run writes the same bytes to `/output/entry.txt`.
